# PegaObusão

Consulte ônibus do Rio em tempo real no mapa. O projeto usa Node.js, dados da SMTR,
GTFS e OpenStreetMap.

## Executar

```bash
npm install
npm start
```

Abra `http://localhost:3001`.

Para testar no celular na mesma rede:

```bash
npm run start:rede
```

Use no celular o endereço de rede exibido pelo terminal.

## Verificar

```bash
npm run check
npm test
```

Consulte [README(1).md](README%281%29.md) para produção, GTFS, variáveis de ambiente e monitoramento.
